# @deepseek-ai/dsh-client-ui-settings-skills

[English](README.md) | 中文

Web 设置中的独立“技能”分区。它不改动“插件”，并提供“我的技能”（本机托管技能包）和“内置技能”（由 Profile 提供、只读）。该分区支持本地搜索、选择文件夹、导入预览、明确确认的同名替换、启用/停用和托管删除。

所有视觉规则均使用 DSH 已有主题 token，因此 `soho-brand-plugin` 等品牌包继续控制颜色和字体，不会与此功能耦合。每张卡片会说明已有的斜杠调用方式：在会话中输入 `/技能名`，选择原生候选项，再补充任务。

## 模型体验

界面只说明已有的 `/技能名` 调用契约，不会改变提示词组装、工具使用或模型选择。

#### KV Cache 影响

无；本包只贡献浏览器设置界面。

## 已知限制与延期工作

- **仅文件夹选择器**：首版有意不接受 ZIP 压缩包。
- **没有在线广场**：如果当前运行时没有打包技能，“内置技能”页可能为空。
