# @deepseek-ai/dsh-host-skill-library

[English](README.md) | 中文

本机技能库的 Host 服务。`SkillLibraryGateway` 提供生成的 `skillLibrary` Remote：列出已安装技能、检查所选文件夹、在确认后导入、替换同名托管技能，以及启用、停用和删除托管技能。它只接受顶层包含一个 `SKILL.md` 的技能包，并会在复制前拒绝符号链接和嵌套技能包。

启用的个人技能位于 `~/.dsh/skills`，停用技能会移动到 `~/.dsh/skills-disabled`。这样原有的文件系统发现机制和 `/技能名` 候选机制仍然是唯一的调用权威。若当前 Profile 提供内置技能根目录，内置技能会以只读形式显示，本包绝不修改它们。

## 模型体验

无。本包仅维护本机设置目录；面向模型的调用继续由 DSH 已有的技能发现机制处理。

#### KV Cache 影响

无；本包不会组装供应商请求。

## 已知限制与延期工作

- **仅支持文件夹导入**：ZIP/压缩包导入会在独立的安全解压边界设计完成后再实现。
- **没有在线广场**：内置页只反映当前运行时/Profile 在本机实际提供的技能。
