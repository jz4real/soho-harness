# 本地文件附件设计

[English](2026-08-26-local-file-attachments-design.md) | 中文

## 目标

向 Web composer 添加完善的本地优先附件流程。用户可选择或拖入 CSV、DOCX、XLSX、PDF、TXT、Markdown 和现有图片类型；会话保留不可变本地副本，在发送前后显示文件卡片，并向已配置模型提供本地提取内容。

## 产品行为

前置 `+` 控件变为附件菜单，包含**上传文件**和现有斜杠命令启动器。将文件拖到应用内任意位置使用相同接收路径。发送前，每个文件以堆叠卡片显示在输入框上方：类型标志、文件名、大小、解析状态和移除操作。发送后，相同文件卡片显示在用户消息旁，供后续读者识别源材料。

首个版本接受 CSV、XLSX、DOCX、PDF、TXT、Markdown、JSON 和已支持的图片格式。它拒绝大于 20 MiB 的文件、一条消息中超过 10 个非图片文件、以及总量超过 50 MiB 的非图片 payload。被拒绝的批次不会部分进入草稿。每个可见错误都指出出错文件和原因。

## 本地优先数据流

1. 浏览器把已接受的 `File` 读取为规范 base64，只发送到 `127.0.0.1` 的本地 Harness host。
2. `attachment-local` 校验 MIME／类型／大小，对原始字节哈希，并以私有权限在 `DSH_HOME/attachments/v2/files` 下写入一个内容寻址对象。
3. 本地提取器读取存储字节并生成有界纯文本上下文。CSV/TXT/Markdown/JSON 使用 UTF-8 解码；DOCX 和 XLSX 使用 ZIP/XML 提取；PDF 使用本地解析器。每个文件提取上限为 60,000 个 Unicode 代码点，每条消息为 160,000，并带明确截断说明。
4. 会话日志存储只包含不可变引用与显示元数据的持久 `file` 块，并存储其后的、以文件名和本地提取提示开头的文本块。提供方适配器接收文本块；不接收原始 office 或 PDF 字节。
5. 历史重载时根据持久引用重建文件卡片。经会话授权的附件路由可下载原始本地对象，而不暴露文件系统路径。

仅选择文件不会上传原始文件。用户提交提示时，提取内容才成为模型输入，并遵循已配置模型提供方的常规隐私边界。

## 架构

`@deepseek-ai/dsh-attachment` 在图片词汇旁新增通用文件词汇：`FileAttachmentRef`、`FileAttachmentLimits`、`EncodedFileAttachment`、`SaveFileAttachment`，以及 store 的校验／保存／读取方法。本地后端拥有内容寻址持久化和提取；它从不调用模型提供方。

会话提示 wire 接受 `file` part。API proxy 在追加用户消息前接收文件，将其转换为持久 `file` 块和有界本地提取文本块，并保持现有图片行为不变。核心 LLM 内容联合类型新增 `file` 块。DeepSeek 和 Pi 适配器有意忽略文件块，因为紧随其后的本地文本块才是提供方可见表示。

对话控制器为图片和文件共用一个草稿 map。`ui-attachment` 渲染 A 风格堆叠卡片，并提供原生文件选择器、拖放目标、剪贴板接收、移除和历史文件卡片。图片预览保持不变。

## 安全与失败处理

- 持久化或会话日志前，将名称缩减为干净的叶文件名。
- MIME 类型由保守的扩展名／类型白名单决定，并在可能时由解析器接收确认；任意 `application/octet-stream` 会被拒绝。
- 文件在其所属会话事件前保存，因此已记录的引用始终指向对象；未使用的内容寻址对象可安全保留。
- 受密码保护或损坏的 DOCX/XLSX/PDF 会被存储，但其卡片报告文本提取不可用；向模型提供简洁本地提示，而不是假装文件已读取。
- 文件下载路由经会话授权，并返回存储的 MIME 类型及安全的 `Content-Disposition` 文件名。

## 本发行版的非目标

- 不支持提供方专用的原始文件上传或云端 Files API。
- 不对扫描 PDF 做 OCR。
- 不自动把 assistant 生成的工作区工件转换为附件卡片。agent 仍可通过现有工具在所选工作区创建它们。
- 不提供跨会话附件库或删除 UI；会话引用继续使用持久本地对象。

## 验收标准

- 选择或拖入 `01_经营数据.csv` 会渲染 A 风格卡片，发送持久文件引用和提取表格文本，模型可根据数据回答问题。
- 选择 `02_项目背景与要求.docx` 会渲染 Word 卡片并发送可读的中文提取文本。
- CSV、XLSX、DOCX、PDF、TXT/Markdown、JSON 和图片保留其类型专属视觉处理。
- 移除草稿文件可阻止上传；无效／超限批次保持在草稿之外并给出本地化错误。
- 重载会话可显示已发送文件卡片并允许下载原始本地文件。
- 现有图片附件测试和所有聚焦新增附件测试均保持通过。
